# The Shape of the Game — NBA History Explorer

An interactive dashboard exploring 80 seasons of NBA history (1947–2026): league-wide trends, player and team stats, a map of franchise locations and relocations, and side-by-side comparisons.

**Live site:** https://royan963.github.io/Nba_History/

The deployed site is a single self-contained file (`index.html`) — no server or install needed. Open it in any modern browser.

## Features

- **Overview** — league scoring, pace and shooting trends with a scrubbable season timeline.
- **Era Evolution** — how the game changed decade by decade (3-point rate, pace, ratings).
- **Leaderboards** — sortable career leaders, filterable by era.
- **Player Explorer** — career trajectory charts, awards and All-NBA/All-Defense honors, an interactive shot-zone court map (with league-average comparison), position mix and play-by-play stats.
- **Team Explorer** — U.S./Canada map of every franchise by season, with relocation paths, plus season-by-season rosters.
- **Compare** — players (aligned by calendar year, age, or experience) and teams (full history or a chosen season).

## Project structure

```
index.html                 Built, deployable dashboard (generated by build.py)
build.py                   Bundles src/ + data/ into index.html
src/
  template.html            Page markup
  styles.css               All styling
  app.js                   All application logic (charts, map, explorers, compare)
  vendor/                  Chart.js, D3, topojson-client (bundled, so it works offline)
data/                      Compact JSON the dashboard embeds (generated, committed)
scripts/
  prep_data.py             Raw CSVs -> data/*.json
  franchise_map.py         Team-name -> franchise lineage, cities and coordinates
  team_colors.py           Franchise colors and badge codes
  build_map_data.js        US/Canada topology -> data/states-10m.json, canada_topo.json
```

## Rebuilding

Editing the UI only needs Python 3:

```bash
python3 build.py        # regenerates index.html from src/ and data/
```

To regenerate the data from the raw stats:

```bash
pip install -r requirements.txt
# unzip the Basketball-Reference CSV dump (nba.zip) into data/raw/
python3 scripts/prep_data.py
python3 build.py
```

To regenerate the map outlines (optional): `npm install && npm run build:map-data`.

## Data notes

Stats come from Basketball-Reference (regular season, 1947–2026). ABA seasons are excluded from league averages. Shot-zone and play-by-play tracking only exist from the 1996/97 season on. The dataset has no game-by-game schedule, so literal head-to-head results aren't available. Team colors are used instead of logos (logos are trademarked).

## Tech

Vanilla HTML/CSS/JS with [Chart.js](https://www.chartjs.org/), [D3](https://d3js.org/) and [TopoJSON](https://github.com/topojson/topojson). Map boundaries from [us-atlas](https://github.com/topojson/us-atlas) and [world-atlas](https://github.com/topojson/world-atlas).
